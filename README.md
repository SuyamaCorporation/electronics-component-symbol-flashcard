# Electronics Component Symbol Flashcard

## 概要
抵抗・コンデンサ・トランジスタ・論理ゲート・電源記号など60種以上の電子回路記号をインライン SVG で描画し、フラッシュカード形式で暗記するアプリ。IEC / ANSI 両規格に対応。

## 機能
- 60+ コンポーネントシンボル（インライン SVG 描画）
  - パッシブ: 抵抗（IEC/ANSI）、コンデンサ（極性あり/なし）、インダクタ、変圧器、クリスタル
  - ダイオード: 標準・ツェナー・LED・ショットキー
  - トランジスタ: NPN BJT・PNP BJT・Nch MOSFET・Pch MOSFET・JFET
  - 論理ゲート: AND・OR・NOT・NAND・NOR・XOR
  - その他: オペアンプ・電圧源・電流源・デジタルGND・シャーシGND・スイッチ・ヒューズ
- フラッシュカード 2モード
  1. シンボルを見てコンポーネント名を答える（3段階評価）
  2. 名前を見て4択のシンボルを選ぶ
- IEC / ANSI 切り替えボタン（トグル）
- カテゴリフィルタ（Passive / Active / Logic / Power）
- 間隔反復（SRS）: 習熟度に応じて優先度を自動調整
- シンボルギャラリー（全種一覧・クリックでジャンプ）
- 正解数・不正解数・習熟数の統計表示
- localStorage でプログレス永続化
- キーボードショートカット（スペース: めくる / 1-3: 評価）

## 使い方
1. モードとカテゴリを選択
2. カードのシンボルを見て（またはクリックして）答えを確認
3. Again / Hard / Good で自己評価（Symbol→Name モード）
4. 4択モードではシンボルをクリックして正誤判定
5. 下部ギャラリーで全記号を一覧確認
